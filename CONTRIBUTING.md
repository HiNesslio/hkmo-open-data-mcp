# Contributing

Contributions are welcome, especially verified official catalogue adapters and registry entries.

A new dataset/adapter must include:

1. official `gov.hk` or `gov.mo` source URL;
2. evidence of dataset title, provider and semantics;
3. API method/parameters/headers only if documented or observable from an official public flow;
4. no private credential or secret;
5. tests showing that a similar-but-different query is **not** accepted as an exact match.
